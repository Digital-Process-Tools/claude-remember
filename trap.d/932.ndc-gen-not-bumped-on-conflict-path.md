rebase rewrites `$SLUG/now.md` to the remote version and the #943 scoped
checkout then rewrites it back -- but this path never calls
`_grc_bump_ndc_gen`, which only the fast-forward and successful-rebase paths
call (the #932 fix).

Reasoned consequence (not reproduced): an NDC consolidation round that
snapshots `now.md` inside that window passes both of `_grc_bump_ndc_gen`'s
own guards at save-session.sh:1386/1405, and trims `NDC_SRC_BYTES` of local
lines it never actually summarised. Those trimmed lines are then committed,
so the data survives in history but is silently cut from the live file by a
process that believes it already summarised them.

confirm, by reading NDC's own guard logic, that it is not actually reachable
in that window and this finding does not hold).
