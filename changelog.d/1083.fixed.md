- Fixed #1083: /remember could still write a handoff note into the wrong project's store for a nested repo or submodule, a sibling folder with no `.git`, or a resumed session that moved to a different folder -- cases a plain "walk up from the current folder" check could never see. SessionStart now pins the correct store for each session, outside every project's own folder, so write-handoff.sh and doctor.sh read that instead of guessing from the current folder. When no pin exists yet (an older session) and more than one folder looks plausible, both now say so and refuse rather than pick one silently.
