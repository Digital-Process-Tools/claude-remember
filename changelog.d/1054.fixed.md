- Fixed #1054: the nested summarizer call left a permanent, empty project folder behind in `~/.claude/projects/` on every single save -- one install saw about 50 a day. The folder came from the CLI's own auto-memory feature scaffolding a `memory/` subfolder for the summarizer's isolated per-call working directory, unrelated to this plugin's own hooks and unaffected by the isolation this plugin already applies to those. `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` is now set for the summarizer call and restored afterward, so no new project folder is created at all; the summarizer never read or wrote auto-memory, so nothing is lost.
