- `hooks.d/after_save/60-git-reconcile.sh`'s `_grc_common_dir()` carried its own copy of the
  Windows drive-letter guard with a bracket expression of `[/\]` (bare slash only) instead of
  the sibling hooks' `[/\\]` (slash and backslash), so `50-git-backup.sh` and
  `hooks.d/before_session_start/50-git-restore.sh` correctly classified a drive-letter path
  spelled with a backslash (`C:\repo\.git`) as absolute while reconcile classified the same
  path as relative (#934).
