- Fixed #1058: `write-handoff.sh` still misrouted a handoff when the Bash cwd had moved deeper than the subdirectory project a session actually started in. The #776 fix compared only two candidates ($(pwd) and the git toplevel) for the session-keyed hint; a directory strictly between the two -- reached only by a `cd` further down -- was invisible to it, and the write fell through to the enclosing repository's own store. Replaced the two-candidate check with a walk of every ancestor from $(pwd) up to the git toplevel, taking the first one whose own store carries this session's hint. Behaviour at the two original candidates is unchanged; only the directories between them are now reachable.
