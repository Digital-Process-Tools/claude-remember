- Fixed #1058: if you started a session in a subfolder of a project and later moved deeper into that subfolder, `/remember` could save your handoff note into the parent project's memory instead of yours. It now finds the folder your session belongs to, and `/remember:doctor` reports the same folder `/remember` writes to.

  **Not fixed yet (tracked in #1083):** a few less common setups can still send the note to the wrong place: resuming a session from a sibling folder, a project inside another git project, and folders that are not in git at all. #1083 will make the session remember its own folder when it starts, which closes all of these.
