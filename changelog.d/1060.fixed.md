- Fixed #1060: an Agent SDK host firing `SessionStart` with `source=resume` on every resumed turn (not once per session) could stack its backgrounded deferred phase (recovery, capture-gap detection) indefinitely -- one reporter measured 42 concurrent processes and host load 275. A second start for a session whose deferred phase is still alive now skips rather than relaunches, via a stale-safe per-session PID marker (`REMEMBER_DIR/tmp/deferred-<session id>.pid`); a dead marker (crash, kill) is treated as stale and replaced, and a different session id is never affected by another session's marker.
