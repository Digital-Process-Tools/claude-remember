- Fixed #1055: renamed the summarizer module and log tag from `haiku` to the model-neutral `summarizer` (`pipeline/haiku.py` is now `pipeline/summarizer.py`), since the configured model is not always Haiku -- a Sonnet or Codex setup's log said "haiku" on every save regardless of what actually ran. The daily log now also records which model ran each summary (the resolved `REMEMBER_MODEL` value, or `codex default` on the Codex route, which passes no model flag). The `model`/`REMEMBER_MODEL` setting and the legacy `haiku.oauth_token` config-key check are unaffected; nothing needs to change in an existing `config.json`.
