- Fixed #1046: If you had several Claude Code windows open in the same project, each saving to a different memory, one window could grab another window's unsaved conversation and save it into the wrong memory. Remember now checks that a conversation really belongs to a memory before rescuing it there, and leaves it alone when it cannot tell. Fixed further by #1087: right after an update, each memory's first start used to get one more chance to grab a window's conversation it shouldn't have -- now it skips a conversation that still looks like it is being written, or that another memory already has evidence for, so only a genuinely old, unclaimed conversation from before the update gets rescued.
