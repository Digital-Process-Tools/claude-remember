Remember now checks that a conversation really belongs to a memory before rescuing it there, and leaves it alone when it cannot tell. Not fixed yet: right after this update, each memory's first start can still save another window's conversation into the wrong place one last time; we chose that over losing an unsaved conversation from before the update, and narrowing it further is planned as a follow-up.
