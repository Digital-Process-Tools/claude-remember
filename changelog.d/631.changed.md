- Changed: the cross-plugin promo at `SessionStart` (#574) now names its own
  off switch in the message itself -- the rendered line ends
  `(off: features.plugin_promos)` (#631). The key was already documented in
  `README.md`, `docs/configuration.md` and `docs/hooks.md`, but a reader who
  has just been interrupted in a terminal is not reading the README; the
  reporter's words were that the promo arrived "without a clear path to
  disabling" it. The hint travels with the line so the path is where the
  interruption is.

  The default is unchanged: the promo still ships **on**, still speaks only
  for a sibling plugin absent from `~/.claude/plugins/installed_plugins.json`,
  and still at most once per `cooldowns.promo_seconds` (7 days). Opt-in was
  considered and rejected -- an opt-in promo channel reaches nobody, which is
  deletion by another name, and the complaint that actually held up was
  discoverability rather than existence.

  The length budget moves 140 -> 150 to fit the hint. That guard only decides
  when an entry is skipped-and-logged; it lengthens nothing that renders. The
  full key is spelled out rather than a shorter `plugin_promos=false` that
  would have fit 140: `config.json` is JSON, so that form is valid syntax
  nowhere, and a hint someone can paste to no effect is worse than none. The
  longest shipped entry now renders at 142 of 150, and a test asserts every
  shipped entry still renders -- a copy edit that busts the budget fails CI
  instead of silently suppressing the promo.
