- Fixed #1070: two carried self-review findings from the v0.42.3 release audit (#1002 round 3). (2) `docs/windows.md` and the three `xfail` `reason=` strings in `tests/test_windows_real_wscript_v0_42_3_1002.py` cited only CI run #38049234152 as OBSERVED evidence for the v0.42.3 traps -- a run that also carried two unrelated test-isolation bugs fixed on a later commit of the same PR (#1010). Both now also cite the clean confirming run on the same PR head, #38051416393, so a future reader is not left cross-referencing the contaminated run's own unrelated failures against the genuine trap evidence.
