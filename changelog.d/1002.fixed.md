- Fixed: on Windows 11 with Windows Terminal as the default terminal, every one of this plugin's four detached saves/consolidations (PostToolUse's save, SessionEnd's self-redetach, SessionStart's consolidation launch, and the Antigravity Stop hook's save) briefly flashed a new console window, because the plain nohup-and-background launch they all used allocates a console on Windows regardless (#1002, reported by fmatamala). Each now routes through a hidden wscript.exe launcher first (`scripts/lib-detach.sh`, `scripts/windows-hidden-run.vbs`, `scripts/lib-detach-pidwrap.sh`), falling back to the unchanged nohup line -- never to skipping the save -- whenever the hidden route is unavailable (wscript.exe or cygpath missing). Non-Windows behaviour is byte-for-byte unchanged. Whether the hidden route genuinely shows no console window is REASONED, not OBSERVED: there is no Windows box in this project's own hands to confirm it, and the reporter is asked to confirm in the pull request.
