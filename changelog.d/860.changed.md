- #860: moved the optional `REMEMBER_OAUTH_TOKEN` / `haiku.oauth_token` recovery token for the
  nested `claude -p` summarizer call to a `plugin.json` `userConfig` option (`oauth_token`,
  `sensitive: true`), configurable through `/plugin` -> `remember` -> Configure instead of an
  environment variable or a `config.json` edit. The legacy env var and config key keep working for
  existing installs but are deprecated: using either now logs a loud `DEPRECATED:` line that
  `/remember:doctor` surfaces, instead of nothing happening. Codex has no `userConfig` mechanism, so
  its recovery path is unchanged. The default, nothing-configured path (the host's own
  `CLAUDE_CODE_OAUTH_TOKEN` / login) is unaffected either way. Reverses the "decided against
  building it" outcome of #869/#860's first pass; see `docs/releasing.md`'s updated
  `MCP_FORWARDS_CREDENTIAL_ENV` section for what moved, what could not move, and why.
