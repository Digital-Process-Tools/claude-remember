- Fixed #1006: the SessionStart consolidation launch now goes through the hidden Windows launcher too, so it no longer flashes a console window on Windows when a staging backlog triggers consolidation at session start. The wiring lives in a new `scripts/consolidation-launch.sh` helper rather than inlined into `session-start-hook.sh` directly, so the Windows-detach library's own compiled size never counts against that hook's already-tight release-tree byte budget. SessionStart backgrounds this launch (a trailing `&` at the call site) rather than waiting on it -- consolidation-launch.sh's own wait on wscript.exe is bounded by a 15s watchdog, not by a few milliseconds, so a synchronous call there would have reintroduced the #646 SessionStart-stall class.
