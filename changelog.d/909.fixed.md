- `_remember_config_tracked_status`'s no-git-binary branch -- the filesystem walk that must
  answer `could-not-tell` and fail closed when no `git` binary is reachable on PATH -- lost its
  only test when #899 removed the legacy-migration suite that exercised it. Added a direct-call
  test asserting `could-not-tell` when an enclosing `.git` is found with git absent from PATH,
  paired with a positive control asserting `untracked` when git is present and the file is
  genuinely untracked, so neither outcome can pass by always answering the other (#909).
