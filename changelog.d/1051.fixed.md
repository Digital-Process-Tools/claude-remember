- Fixed (#1051): on the first session of a new day, memory could be injected
  oversized -- over the limit meant to keep it from being silently cut off by
  Claude Code's own output cap. This happened because a leftover copy of
  yesterday's memory was being compared against freshly built memory from
  today, and the two never matched, so the size limit gave up instead of
  trimming. Now the size limit is enforced correctly even on the first
  session of a new day.
