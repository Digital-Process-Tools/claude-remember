- Changed: v0.45.1 changed how memory recovers a stuck save lock (a change
  meant to make a hung save unstick itself automatically). That change
  turned out to be able to let two saves run at the same time, which is
  worse than the stuck-lock problem it was trying to fix. v0.45.2 puts the
  save lock back exactly the way it worked in v0.45.0, before that change --
  the fix for the Ubuntu 26.04 double-save issue (#1108) stays in place.
  The stuck-lock auto-recovery idea is being redesigned from scratch, with
  more review time, as its own separate change later. #1101 and #1103 (the
  stuck-lock behavior this removes) are reopened (#1131).
