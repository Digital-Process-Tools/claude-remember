- Fixed (#501): `REMEMBER_BRANCH_CMD`'s stdout was substituted into the summarizer prompt with no newline bound -- `$(...)` only strips trailing newlines, so a resolver that printed more than one line wrote arbitrary content at column 0 of the prompt. A multi-line result is now refused outright (logged the same WARNING-and-fall-through-to-`git branch` as a non-zero exit or empty stdout), rather than truncated silently to its first line.
