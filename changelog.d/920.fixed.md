- Fixed #920: three gaps in #902's `REMEMBER_DIR` safety guard. `bootstrap-dirs.sh`
  and five other `mkdir -p "$REMEMBER_DIR/..."` call sites across
  `post-tool-hook.sh`, `session-start-hook.sh`, `session-end-hook.sh` and
  `write-handoff.sh` now refuse to build the tree when `REMEMBER_DIR` is unsafe
  (newline/CR-bearing or not absolute), gated on a new `REMEMBER_DIR_UNSAFE` flag
  `lib-memory-dir.sh` exports once at the single place every one of them resolves
  `REMEMBER_DIR`. A `FATAL` logged through `log()` while that guard's sink is active
  now always reaches stderr, instead of a successful append to `/dev/null` silently
  swallowing it. A UNC project directory (`\\\\server\\share\\proj`) is now accepted
  as an absolute path by both guard predicates rather than misclassified as unsafe.
