- Fixed: on Windows, every consolidation launch left a stray file named `nul`
  (holding a process id) in the folder Claude was started from. Git Bash turns
  the `/dev/null` placeholder into `nul` on its way through the hidden-launch
  helper, and the helper only recognised the literal `/dev/null`, so it wrote
  to a real file called `nul` instead of skipping the step. The helper now treats
  `nul` (any case) the same as `/dev/null` (#1132).
